# Отчет о выполнении задачи

## Разработка модуля автоматического формирования признаков для прогнозирования параметров ионосферы

В рамках задачи разработан модуль автоматического формирования информативных признаков для последующего использования в моделях машинного обучения. Модуль предназначен для обработки временных рядов ионосферных параметров GIRO и данных космической погоды, приведенных к единой временной сетке.

Реализовано автоматическое создание следующих групп признаков:

- временные признаки: час суток, месяц, день года;
- циклические признаки: `hour_sin`, `hour_cos`, `month_sin`, `month_cos`, `doy_sin`, `doy_cos`;
- признаки текущего состояния ионосферы;
- лаговые признаки для ионосферных и геофизических параметров;
- разностные признаки по заданным временным лагам;
- целевые переменные для заданных горизонтов прогноза;
- координатные признаки станции при наличии метаданных.

Настройки формирования признаков вынесены в конфигурационный файл, что позволяет менять набор целевых параметров, горизонты прогноза, лаги и порог покрытия признаков без изменения программного кода.

На вход модуль принимает нормализованные станционные временные ряды. На выходе формируются готовые обучающие таблицы отдельно для каждой станции. Такой формат позволяет запускать обучение независимо по станциям, контролировать качество данных и масштабировать вычисления при большом прогоне моделей.

Для контроля результата формируются сводные данные по обработанным станциям: количество строк, количество сформированных признаков и перечень признаков, пригодных для обучения.

Подготовлен набор данных по 41 станции на 15-минутной временной сетке за период 2024-2025 гг. Станции разделены по объему данных на крупные, средние и малые, что удобно для планирования дальнейших вычислений и запуска моделей на другом компьютере.

Модуль Feature Engineering интегрирован с ML-пайплайном. Подготовлен конфиг для прогноза параметра `foF2` на горизонте 24 часа с использованием моделей `LinearRegression`, `ElasticNet`, `RandomForest`, `XGBoost` и `CatBoost`.

После обработки каждой станции результаты сохраняются в отдельной структуре: метрики, прогнозы, важность признаков, краткое описание запуска и Markdown-отчет с сезонной таблицей метрик и текстовым анализом. В отчет автоматически включаются только те метрики, которые реально присутствуют в результатах.

Работоспособность проверена на собранных данных: feature-таблицы читаются корректно, dry-run ML-конфига успешно определяет train/test-разбиения, пакетный запуск по списку станций формирует корректный план обработки, тесты проекта проходят успешно.

Итог: модуль автоматического формирования признаков разработан, интегрирован в общий пайплайн подготовки данных и готов к использованию в большом прогоне моделей машинного обучения.
